# ☀️ Surya-Shakti Solar Monitor

## 📌 Project Overview

Surya-Shakti Solar Monitor is an AI-based Android application developed using Kotlin and Jetpack Compose to help users monitor solar energy generation and electricity consumption.

The application calculates energy savings, displays energy efficiency scores, provides AI-based energy optimization tips, and helps users track previous usage history.

---

## 🚀 Features

- User Login & Signup Authentication using Firebase
- Solar Energy Generation Input
- Electricity Consumption Tracking
- Energy Savings Calculation
- Energy Efficiency Score Display
- AI-based Energy Saving Tips
- Previous Usage Tracking
- Modern UI using Jetpack Compose
- Firebase Backend Integration
- Input Validation & Error Handling

## 🎯 Problem Statement

Many households using solar panels struggle to monitor energy generation and electricity consumption efficiently. This project provides a simple solution to calculate savings, track energy usage, and encourage sustainable energy practices.

---

## 📊 Formula Used

### Net Energy

Net Energy = Solar Generation - Consumption

### Savings

Savings = Net Energy × 5

### Energy Score

Energy Score = Generation / (Generation + Consumption) × 100
